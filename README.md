# 힘 단위 변환기

## 용도

힘 값을 다른 힘 단위로 변환하는 Python GUI 프로그램입니다. 입력 단위와 출력 단위를 선택하고 계산 결과를 확인할 수 있으며, 프로그램 실행 중 계산 기록을 표시합니다.

지원 단위:

- `N` (뉴턴)
- `kN` (킬로뉴턴)
- `MN` (메가뉴턴)
- `kgf` (킬로그램힘)
- `lbf` (파운드힘)

## 필요 환경

- Python 3.6 이상
- Python 환경에서 `tkinter`를 사용할 수 있어야 합니다.

정확한 최소 Python 버전은 코드에서 사용되는 f-string 문법을 기준으로 적었습니다. `tkinter`의 설치 여부는 사용하는 Python 배포판과 환경에 따라 다를 수 있습니다.

## 실행 명령

프로젝트 폴더에서 다음 명령을 실행합니다.

```powershell
python force_converter.py
```

`python` 명령이 해당 Python 3 실행 파일을 가리키지 않는 환경에서는 Python 3 실행 파일 이름에 맞춰 명령을 바꾸세요.

## 입력 예시

1. 창의 값 입력란에 `1`을 입력합니다.
2. 입력 단위에서 `kN`, 출력 단위에서 `N`을 선택합니다. 기본 선택값도 `kN`과 `N`입니다.
3. `계산` 버튼을 누르거나 입력란에서 Enter 키를 누릅니다.

결과는 `1 kN = 1,000.00 N`으로 표시됩니다. `초기화` 버튼은 입력값과 계산 기록을 지웁니다.

### 잘못된 입력 예시

값 입력란에 `abc`처럼 숫자로 변환할 수 없는 내용을 입력하고 계산하면 `오류: 올바른 숫자(정수 또는 실수)를 입력해주세요.`라는 안내가 표시됩니다.

## 하중 데이터 분석기

`load_analyzer.py`는 같은 폴더의 `load_bad.csv`를 읽어 하중과 응력을 분석합니다. 입력 CSV는 첫 줄을 헤더로 사용하며 다음 열을 포함해야 합니다.

| 열 이름 | 의미 | 단위 |
| --- | --- | --- |
| `time_s` | 측정 시간 | s (초) |
| `force_N` | 하중 | N (뉴턴) |

### 필요한 환경과 실행

Python 환경에 `pandas`와 `matplotlib`가 필요합니다. 프로젝트 가상환경을 사용하는 경우 프로젝트 폴더에서 실행합니다.

```powershell
.\.venv\Scripts\python.exe load_analyzer.py
```

### 계산과 출력

- 코드의 `area_mm2 = 100` 설정을 사용해 `stress_MPa = force_N / area_mm2`로 응력을 계산합니다. 면적 단위가 mm²이고 하중 단위가 N이므로 응력 단위는 MPa입니다.
- 최대 하중과 최대 응력, 각 최대값이 발생한 시간, 기준 응력 `6 MPa`를 초과하는 유효 데이터 개수를 콘솔에 출력합니다. 최대 응력은 그래프에서 강조하고 값도 표시합니다.
- 결과 CSV는 입력 파일을 덮어쓰지 않고 같은 폴더의 `load_result.csv`에 저장합니다. 여기에는 유효한 행의 `time_s`, `force_N`과 계산한 `stress_MPa`가 포함됩니다.
- 시간-응력 그래프는 같은 폴더의 `stress_plot.png`로 저장합니다. x축은 `Time (s)`, y축은 `Stress (MPa)`이며 데이터 점을 선으로 연결합니다.
- 콘솔에는 제외한 행수와 유효한 데이터 수를 함께 표시합니다.

### 오류 처리

- `time_s` 또는 `force_N` 값이 빈칸이거나 숫자로 변환할 수 없으면 해당 CSV 행의 줄 번호(헤더 포함)와 문제 열 및 값을 알립니다. 해당 데이터 행은 계산, 결과 CSV, 그래프에서 제외됩니다.
- 한 행에서 두 열 모두 잘못된 경우 각 문제 열을 각각 알리지만, 제외 행수는 한 번만 셉니다.
- 유효한 데이터가 하나도 없으면 계산과 그래프 생성을 중단하고 안내합니다.
- 필수 열이 없으면 누락된 열 이름을 포함한 오류를 발생시킵니다.
