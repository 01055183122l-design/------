# 힘 단위 변환기

## 용도

힘 값을 다른 힘 단위로 변환하는 Python GUI 프로그램입니다. 입력 단위와 출력 단위를 선택하고 계산 결과를 확인할 수 있으며, 프로그램 실행 중 계산 기록을 표시합니다.

지원 단위:

- `N` (뉴턴)
- `kN` (킬로뉴턴)
- `MN` (메가뉴턴)
- `kgf` (킬로그램힘)
- `lbf` (파운드힘)

## 필요 환경

- Python 3.6 이상
- Python 환경에서 `tkinter`를 사용할 수 있어야 합니다.

정확한 최소 Python 버전은 코드에서 사용되는 f-string 문법을 기준으로 적었습니다. `tkinter`의 설치 여부는 사용하는 Python 배포판과 환경에 따라 다를 수 있습니다.

## 실행 명령

프로젝트 폴더에서 다음 명령을 실행합니다.

```powershell
python force_converter.py
```

`python` 명령이 해당 Python 3 실행 파일을 가리키지 않는 환경에서는 Python 3 실행 파일 이름에 맞춰 명령을 바꾸세요.

## 입력 예시

1. 창의 값 입력란에 `1`을 입력합니다.
2. 입력 단위에서 `kN`, 출력 단위에서 `N`을 선택합니다. 기본 선택값도 `kN`과 `N`입니다.
3. `계산` 버튼을 누르거나 입력란에서 Enter 키를 누릅니다.

결과는 `1 kN = 1,000.00 N`으로 표시됩니다. `초기화` 버튼은 입력값과 계산 기록을 지웁니다.

### 잘못된 입력 예시

값 입력란에 `abc`처럼 숫자로 변환할 수 없는 내용을 입력하고 계산하면 `오류: 올바른 숫자(정수 또는 실수)를 입력해주세요.`라는 안내가 표시됩니다.
